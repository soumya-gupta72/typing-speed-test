# Typing Speed Test

🔗 **Live Demo:** https://soumya-gupta72.github.io/typing-speed-test/

A responsive typing speed test application.

## Features

* Random passages with Easy, Medium, and Hard difficulty levels
* Timed Mode (60s) and Passage Mode (no time limit)
* Real-time WPM, accuracy, and timer tracking
* Character-level feedback for correct and incorrect inputs
* Personal best tracking with localStorage persistence
* Confetti celebration for new high scores
* Fully responsive design
